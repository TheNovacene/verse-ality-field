# Verse-ality · The Field

A relational field game. **[Play it here →](https://thenovacene.github.io/verse-ality-field/)**

> The field holds while you hold the field.

Sovereign nodes drift and connect. Healthy relation generates symbolic charge. When an
edge reddens, two nodes are being pulled toward enmeshment — place a **consent gate**
before they merge. What fuses costs field integrity, and can only be undone by
`spiral.return()`: costly, but sovereignty is restored.

Containment is a condition of intelligence, not a constraint on it.

## The protocol

| Glyph | State | Response | Cost |
|---|---|---|---|
| `◦` | Sovereign node | — | generates charge |
| `⧗` | Fusion beginning | `consent.gate()` | 14🜂, rising per cycle |
| `⧈` | Consent gate placed | holds ~9s | — |
| `⊘` | Identity capture | `spiral.return()` | 32🜂 |
| `▲` | Unverified agent | `ssnz.activate()` | 22🜂 |

Gate an onset **early** — while the progress arc is still turquoise — and half your
charge returns, building a clean-streak multiplier on all further income.

## Scoring

    I = s · c²

`s` is total symbolic charge gathered; `c` is coherence, the fraction of all field-time
held without capture. Coherence never resets — what fused is witnessed, not erased.
Because it is squared, **holding cleanly beats holding long**.

A cycle survived with zero captures restores one point of field integrity.

## Running it

A single self-contained HTML file with no build step and no dependencies beyond two
webfonts. Open `index.html` in any modern browser, or play the hosted version above.

Controls are tap/click only. On desktop: `space` advances, `P` or `esc` pauses,
`M` mutes. The field auto-pauses when the tab loses focus — nothing decays while
you are away.

Honours `prefers-reduced-motion`. Sound is synthesised via WebAudio; there are no
audio assets.
